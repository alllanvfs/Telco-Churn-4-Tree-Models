# Telco Customer Churn Prediction - Tree Based Methods

## Overview

This repository presents a project for predicting customer churn in the telecommunications sector using tree-based methods. Using the **Telco-Customer-Churn.csv** dataset, the project performs an exploratory data analysis, applies data preprocessing techniques, and tests **four** tree-based classification models to predict the likelihood of customer churn.

## Objectives

- **Exploratory Data Analysis:** Investigate the dataset's structure and key characteristics to identify variables relevant to predicting churn.
- **Preprocessing:** Handle missing values and perform categorical variable encoding to prepare the data for modeling.
- **Modeling:** Implement and compare four tree-based classification models:
  - Decision Tree Classifier
  - Random Forest Classifier
  - Ada Boosting Classifier
  - Gradient Boosting Classifier
- **Evaluation:** Compare the models using performance metrics such as confusion matrices and, if applicable, additional metrics (e.g., accuracy, ROC curves).

## Project Structure

- **Telco-Customer-Churn.csv:** Dataset containing customer information from a telecommunications company.
- **tree_based_methods.ipynb:** Jupyter Notebook that contains the complete project pipeline, from data exploration to model evaluation.

## Key Technologies and Libraries

- **Python 3**
- **Pandas and NumPy:** For data manipulation and processing.
- **Matplotlib and Seaborn:** For data visualization.
- **Scikit-Learn:** For implementing machine learning models and evaluation metrics.
